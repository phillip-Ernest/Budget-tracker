# My Budget Tracker

## Project Description

My Budget Tracker is a simple web page designed to help users record and view their personal expenses. The project was created using HTML and CSS.

The Week 2 version improves the original Budget Tracker by adding a structured expense form, an expense table, multimedia content, and advanced CSS selectors.

## Files in the Project

### 1. index.html

The `index.html` file contains the main structure of the Budget Tracker webpage.

It includes:

* A page heading and introduction
* An expense entry form
* Text, number, and date inputs
* A category dropdown with multiple options
* An Add Expense button
* An expenses table
* An image
* An embedded budgeting video using an iframe
* A footer

### 2. style.css

The `style.css` file controls the appearance of the webpage.

It includes:

* Page layout and spacing
* Header and footer styling
* Form styling
* Table styling
* Button styling
* Image and iframe styling
* Advanced CSS selectors

Advanced selectors used include attribute selectors, child selectors, pseudo-class selectors, and `nth-child` selectors.

### 3. README.md

This file explains the project, its purpose, and what each file does.

## HTML Table

The expenses table uses:

* `<table>`
* `<thead>`
* `<tbody>`
* `<tr>`
* `<th>`
* `<td>`

The table displays example expenses with their amount, category, and date.

## Expense Form

The form allows a user to enter:

* Expense name
* Amount
* Category
* Date

The category dropdown contains more than five options, including Food, Transport, Education, Entertainment, Shopping, and Other.

## Multimedia

The webpage contains:

* An image related to personal budgeting
* An embedded budgeting video using an `<iframe>`

## Technologies Used

* HTML5
* CSS3

## Project Goal

The goal of this project is to demonstrate proper HTML structure, form elements, tables, multimedia elements, and advanced CSS selectors while creating a simple and visually organized Budget Tracker.
